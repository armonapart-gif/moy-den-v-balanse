# Abricot Stories — система Instagram Stories на Remotion

Переиспользуемый шаблон для Stories Зебунисо Солиевой и Центра ЗОЖ «Абрикосовый рай».
Принцип: **код не меняется — меняется монтажный лист** (`src/episodes/*.json`).

> Статус: подготовительный этап. Готовы схема данных, токены дизайна, инструмент транскрипции и транскрипты тестовых видео.
> Компоненты Stories и рендер — после утверждения монтажного листа.

## Формат

1080×1920, 30 fps, 9:16. Каждая Story — отдельная композиция → отдельный MP4 (`out/<episode>/<NN>-<id>.mp4`).
Safe zones (px): сверху 270, снизу 380, по бокам 64 — всё важное (текст, логотип) внутри. Исходники 720×1280 масштабируются ×1.5 без обрезки и искажения; для видео с другим соотношением сторон — `fit: cover|contain` с `focusY`.

## Структура

```
stories/
  data/transcripts/         транскрипты: слова с таймингами (JSON)
  docs/                     отчёты подготовки
  public/source/            исходные видео (в git не попадают)
  src/
    theme/tokens.ts         цвета, шрифты, safe zones — единственный источник
    lib/types.ts            схема монтажного листа (zod) — контракт для ChatGPT/Codex
    lib/subtitles.ts        (след. этап) транскрипт → блоки по 1–2 строки, выделение ключевых слов
    components/             (след. этап) Subtitles, Headline, Logo, SafeZoneGuide
    stories/                (след. этап) VideoStory, TalkingHeadStory, TextStory,
                            PollStory, QuoteStory, CTAStory, BrollStory
    episodes/               монтажные листы (JSON)
    Root.tsx                регистрирует по композиции на каждую Story эпизода
  tools/
    transcribe.py           русская речь → JSON со словами и таймкодами (офлайн)
    render-episode.mjs      (след. этап) рендер всех Stories эпизода в отдельные MP4
```

## Монтажный лист (контракт данных)

Эпизод = список Stories. Тип выбирает компонент; все тексты, тайминги и подсветки — данные:

```json
{
  "id": "2026-10-test-01",
  "title": "Мини-продукт: тест",
  "stories": [
    {"type": "talkingHead", "id": "s01",
     "clip": {"src": "part1.mov", "from": 0.8, "to": 22, "transcript": "data/transcripts/part1.json"},
     "subtitles": {"highlight": ["вебинар", "мини-продукт"]}},
    {"type": "poll", "id": "s05", "question": "Какое название вам ближе?", "hint": "Место под опрос Instagram оставлено"},
    {"type": "cta", "id": "s06", "headline": "Хотите вебинар?", "action": "Напишите в комментариях", "keyword": "ГОЛОВА"}
  ]
}
```

Полная схема — `src/lib/types.ts`. Тайминги `from/to` — секунды исходного файла; субтитры берутся из транскрипта в этом диапазоне, текст можно править в монтажном листе, не трогая код.

## Транскрипция новых видео

```
pip install sherpa-onnx numpy        # + ffmpeg в PATH
python3 tools/transcribe.py video.mov --out data/transcripts
```

Модели скачиваются автоматически с GitHub Releases (Hugging Face в некоторых средах закрыт). Автораспознавание всегда вычитывается человеком перед монтажом: имена и редкие слова модель путает.

## Дизайн-принципы (из инструкции «Современный сторителлинг для Reels»)

Oswald Bold; оранжевый `#F29A32` — ключевые слова, зелёный `#008E3C` — редкая деталь, молочный `#FFF9EE` — основной текст. Текст прямо на видео, без плашек, карточек и декоративных линий; читаемость — мягким затемнением и тенью. Анимация — одно спокойное появление.
